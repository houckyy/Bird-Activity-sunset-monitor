Terrain & Activity Map

Topographic base map, with a grid of nearby points sampled from Open-Meteo so cloud cover, wind, and precipitation vary across the terrain, not just at one pin. Each point also checks real elevation data along its sunset sightline - a nearby ridge shows up in the popup as ending direct light earlier there, which matters for shooting at low ISO, but it does not discount the Sunset Quality score itself: the color show depends on the sun's descent below the geometric horizon, which happens whether or not a mountain blocks your direct view of the disc. The Bird Activity layer always uses the weather/astronomy model (real eBird sightings, if you've set a key, only drive the single-point score on the Dashboard - sampling eBird at 25 grid points per refresh isn't practical).

Units

Bird data source

Paste a free eBird API key to switch the Bird Activity Meter to real, recently-reported sightings near you instead of a weather-based estimate. Get one in about 2 minutes at ebird.org/api/keygen - it's free, instant, no approval wait. The key is stored only in this browser (localStorage), never sent anywhere but eBird's own API.
